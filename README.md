# Oasis – Custom Ghost Theme 🌿

Oasis is a modern, clean, and fully responsive custom theme designed for the Ghost CMS. It is built for blogs, tech platforms, NPO websites, and knowledge-sharing communities with a focus on speed, readability, and user experience.

---

## 🚀 Features

- ✅ Fully Responsive Design (Mobile, Tablet & Desktop)
- ✅ Clean & Minimal UI
- ✅ Custom Homepage Sections
- ✅ Tag-based Custom Titles
- ✅ Team Section with Profile Cards
- ✅ Testimonials Section
- ✅ Auto Post Slider
- ✅ Social Media Integration
- ✅ SEO Friendly
- ✅ Fast Loading Performance
- ✅ Custom CSS & JavaScript Support
- ✅ Compatible with Latest Ghost Version

## ⚙️ Installation

1. Clone or download the repository:
```

git clone https://github.com/Sakthi10122004/Theme-For-Oasis-Ghost.git

```

2. Upload the theme:
- Ghost Admin → **Settings**
- **Design**
- **Change Theme**
- Upload ZIP

3. Activate the theme.

4. Restart Ghost:
```

ghost restart

```
